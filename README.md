# DevJoint Data Science Internship

A repository covering 4 weeks of data science projects.

## 📁 Structure

- **Week1_Tasks** — Data loading, missing value handling, outlier detection, feature engineering, visualization, final conclusion
- **Week2_Tasks** — Descriptive statistics, hypothesis formulation, test execution, interpretation of results, final conclusion
- **Week3_Tasks** — Train/test split, preprocessing pipeline, model training, metrics, cross-validation, feature importance
- **Week4_Tasks** — Problem framing, EDA & cleaning, model comparison, hyperparameter tuning, final evaluation, model saving, business report

Each week's folder contains sequential checkpoint notebooks (`checkpoint1`, `checkpoint2`, ...).

## 🛠 Tech Stack
Python · pandas · numpy · scikit-learn · matplotlib/seaborn · joblib
